# VAC2026

This repository contains the notebooks and materials for the VAC 2026 learning track focused on Retrieval-Augmented Generation (RAG), LangChain workflows, and generative AI experimentation.

## Contents

- `Day 2/` — notebooks covering different RAG and retrieval patterns
  - `1 Naive_RAG.ipynb`
  - `2 RAG_News_Webpage_LangChain.ipynb`
  - `3 RAG_News_Webpage_Kaggle_Qwen3_4bit.ipynb`
  - `4 Advanced_RAG.ipynb`
  - `5 Query_Decomposition.ipynb`
  - `6 Parent_child_retrievel.ipynb`
  - `small.pdf` — sample document used in the RAG examples

## Project goals

- Explore naive and advanced RAG pipelines
- Work with LangChain and embedding-based retrieval
- Compare different retrieval strategies and query decomposition patterns
- Learn practical patterns for grounded LLM applications

## Environment

These notebooks typically depend on Python libraries such as:

- `langchain`
- `langchain_google_genai`
- `chromadb`
- `sentence-transformers`
- `pypdf`
- `huggingface_hub`

Install dependencies as needed for your local environment before running the notebooks.

## Notes
